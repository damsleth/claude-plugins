# claude-plugins

Claude Code marketplace for my mods, skills and other plugins. The homebrew-tap of Claude Code.

## Install

```
/plugin marketplace add damsleth/claude-plugins
/plugin install <plugin>@damsleth
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [clean-view](plugins/clean-view) | Collapses diffs and tool output to one dim line, hides the prompt hint and logo notices. `/clean` toggles. ctrl+o does not expand tool rows. |
